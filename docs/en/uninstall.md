# Uninstall

```bash
./scripts/uninstall.sh
```

Containers stop. The volume (database and archives) is kept.

```bash
./scripts/uninstall.sh --purge
```

also deletes that volume. Invoices already filed at SUPER PDP and the Invoice Ninja fields are not removed: delete the Invoice Ninja webhook and, if you change platform, the directory entry, in those products’ own interfaces. This software does not change a regulatory mandate by itself.
